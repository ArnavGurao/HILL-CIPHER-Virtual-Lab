# Hill Cipher Virtual Lab

An interactive virtual lab for learning the Hill Cipher, a cryptographic technique that uses matrices to encrypt and decrypt text.

## Features

- Theory explaining the Hill Cipher and its security limitations
- Step-by-step encryption and decryption procedures
- Interactive encryption and decryption simulations
- Test records to track results
- A quiz to check understanding

## Technologies Used

HTML, CSS, and JavaScript.
